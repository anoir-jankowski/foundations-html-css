# Foundations: HTML & CSS

This project contains my first hands-on work with HTML and CSS.  
The goal was to understand and apply the fundamental structure of web pages and basic styling techniques.


## Features

- Semantic HTML structure (header, main, footer)
- Basic form with validation (name & email)
- Simple list structure
- Responsive viewport setup
- Clean CSS layout with Flexbox
- Basic UI styling for inputs and buttons


## Technologies

- HTML
- CSS


## What I learned

- Structuring a webpage using semantic HTML
- Creating and styling forms
- Using Flexbox for layout
- Applying basic CSS styling and spacing
- Understanding how HTML and CSS interact


## How to run

1. Clone the repository
2. Open `index.html` in your browser
